# インターメソッド株式会社 コーポレートサイト

「ソフトウェアで、次の当たり前をつくる。」をコンセプトにした、架空の企業「インターメソッド株式会社」のコーポレートサイト（ランディングページ）です。

ビルドツールやパッケージのインストールは不要で、`index.html` をブラウザで開くだけで表示できる**単一 HTML ファイル**構成になっています。

## 概要

| 項目 | 内容 |
| --- | --- |
| 構成 | `index.html` 1ファイル（CSS / JavaScript を内包） |
| 言語・技術 | HTML5 / CSS3 / Vanilla JavaScript |
| 依存関係 | なし（外部ライブラリ・CDN 未使用） |
| デザイン | ダークテーマ、グラデーションを用いたモダンな配色 |
| 対応 | レスポンシブ（スマートフォン〜デスクトップ） |

## ページ構成

- **ヘッダー** — スクロールに応じて背景がぼかし表示に切り替わる固定ヘッダー。モバイルではハンバーガーメニューを表示
- **お知らせ欄** — プレスリリースや採用情報などを横方向にループ表示するティッカー
- **ヒーロー** — キャッチコピーと CTA ボタン。導入企業数などの数値はスクロール時にカウントアップ
- **サービス** — クラウド・SaaS 開発 / AI・データ活用 / 業務システム・DX の3領域を紹介
- **私たちについて** — 社名の由来と3つの強み
- **実績** — 物流・小売・製造の導入事例3件
- **お問い合わせ** — メール・電話への CTA
- **フッター** — サイトマップと会社情報

### 主な動作

- `IntersectionObserver` による各セクションのスクロールイン表示
- 実績数値のカウントアップアニメーション
- ナビゲーションのスムーススクロール（`scroll-behavior: smooth`）

## 表示手順（ブラウザで index.html を開く）

### 方法1: ファイルをダブルクリックする

1. エクスプローラーでこのフォルダーを開きます
2. `index.html` をダブルクリックします
3. 既定のブラウザでサイトが表示されます

別のブラウザで開きたい場合は、`index.html` を右クリックし「プログラムから開く」からブラウザを選択してください。

### 方法2: コマンドラインから開く

PowerShell（Windows）:

```powershell
start index.html
```

macOS:

```bash
open index.html
```

Linux:

```bash
xdg-open index.html
```

### 方法3: ローカルサーバーで開く

`file://` ではなく `http://` で確認したい場合は、簡易サーバーを起動します。

Python 3 がインストールされている場合:

```bash
python -m http.server 8000
```

Node.js がインストールされている場合:

```bash
npx serve .
```

起動後、ブラウザで `http://localhost:8000` にアクセスします。

> 外部リソースを読み込んでいないため、方法1・2（`file://` で直接開く）でもすべての機能が正常に動作します。

## 動作環境

Chrome / Edge / Firefox / Safari の最新版を推奨します。`IntersectionObserver` と CSS カスタムプロパティを使用しているため、Internet Explorer では正しく表示されません。

サイト内に記載されている社名、実績数値、メールアドレス（`contact@intermethod.example`）、電話番号、所在地はすべてサンプル用の架空の情報です。
